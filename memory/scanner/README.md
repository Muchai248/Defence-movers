# Security Scanner Tools - Educational Purpose

**⚠️ IMPORTANT**: This directory contains security tools for **educational purposes only**.
- Only use on systems you own or have explicit written authorization to test
- Never use against systems without permission
- Unauthorized use may violate computer crime laws

## ✅ Legitimate Tools Included

These tools are for **defensive security** and **authorized testing**:

1. **Nmap** - Network discovery and security auditing
2. **Wireshark** - Network protocol analyzer
3. **Nikto** - Web server scanner
4. **Recon-ng** - OSINT reconnaissance framework
5. **TCPdump** - Packet capture tool

## ❌ Tools NOT Included (Attack/Exploitation)

The following tools are NOT included because they are designed for exploitation:

- Metasploit (exploitation framework)
- BeEF (browser exploitation)
- SQLmap (SQL injection exploitation)
- John the Ripper, Hashcat, Hydra (password cracking)
- Ettercap (MITM attacks)
- Aircrack-ng (WiFi cracking)
- Social-Engineer Toolkit (phishing)
- Cobalt Strike (adversary simulation)

**For these tools, use authorized practice platforms like TryHackMe or HackTheBox.**

## 📚 Educational Alternatives

Instead of installing dangerous tools locally, use:

- **TryHackMe** (tryhackme.com) - Free cybersecurity labs
- **HackTheBox** (hackthebox.com) - Penetration testing practice
- **OverTheWire** (overthewire.org) - Security wargames
- **PortSwigger Academy** (portswigger.net/web-security) - Web security education

## 🎯 Safe Learning Environment

For safe educational practice:
1. Use virtual machines
2. Practice on authorized platforms
3. Set up home lab with your own systems
4. Always get written authorization before testing
5. Document your learning
